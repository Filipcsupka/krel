# Support

Use GitHub issues for public support:

- bug reports
- feature requests
- documentation gaps
- questions about expected behavior

Before opening an issue, check the README and docs:

- [Getting Started](docs/getting-started.md)
- [Development Guide](docs/development.md)
- [Roadmap](docs/roadmap.md)

Do not share secrets, kubeconfig credentials, tokens, sensitive YAML, or private logs in public issues.

For security issues, follow [SECURITY.md](SECURITY.md).
